# نقش‌نگار | جامعه و بازارچهٔ چهل‌تکه‌دوزی

نقش‌نگار یک فضای یکپارچه برای یادگیری، طراحی، نمایش آثار، گفت‌وگو و خریدوفروش ابزار و محصولات چهل‌تکه‌دوزی است. وب‌سایت و اپلیکیشن اندروید از یک کدبیس React/Vite + Capacitor استفاده می‌کنند و سرویس‌های احراز هویت، داده و فایل بر پایهٔ Supabase هستند.

## ساختار مخزن

- naqsh-negar-source.zip — بستهٔ اصلی کد وب و Android.
- source-overlay/ — لایهٔ تغییرات نسخهٔ اجتماعی؛ CI و Vercel آن را پس از استخراج بستهٔ اصلی اعمال می‌کنند.
- source-overlay-b64/ — بستهٔ فشردهٔ overlay در قطعه‌های base64 که با scripts/restore-overlay.sh بازیابی می‌شود.
- .github/workflows/ — ساخت APK و انتشار GitHub Pages.
- vercel.json — فرمان‌های ساخت Vercel برای استخراج و ساخت بستهٔ اصلی به‌همراه overlay.
- docs/ — ممیزی فنی و نقشهٔ توسعه.

## قابلیت‌های موجود در پایهٔ پروژه

- ورود و ثبت‌نام، پروفایل و نقش‌های کاربری
- گالری آثار با رضایت انتشار، بازبینی مدیر و گزارش محتوا
- گفت‌وگوهای موضوعی، پیام خصوصی و پرسش‌وپاسخ دوره‌ها
- فروشگاه، سبد خرید، سفارش و ارسال رسید پرداخت برای بررسی مدیر
- آموزش‌ها، دوره‌ها، پروژه‌های شخصی و طراح بلوک چهل‌تکه
- پنل مدیریت محتوا، سفارش‌ها، رسیدها و پشتیبانی

## ارتقای اجتماعی — فاز اول

- فید اجتماعی برای آثار کاربران
- انتشار تصویر تا ۱۰ مگابایت و ویدئو تا ۱۰۰ مگابایت
- لایک، دیدگاه، دنبال‌کردن و ذخیرهٔ پست
- صفحهٔ ریلز عمودی با پخش خودکار و توقف ویدئوهای خارج از دید
- صف مدیریت محتوا برای مدیران: انتشار، پنهان‌سازی و حذف با ثبت رویداد مدیریتی
- مهاجرت Supabase با جدول‌های مستقل، RLS و bucket خصوصی qnr-social-media
- پاک‌سازی فرادادهٔ EXIF تصاویر پیش از بارگذاری

**نکتهٔ عملیاتی:** فایل مهاجرت فاز اول در source-overlay/supabase/migrations/20261126093000_qnr_social_network.sql است. سه مهاجرت اجتماعی در Supabase پروژهٔ نقش‌نگار اجرا شده‌اند و در ledger ثبت شده‌اند: شبکهٔ اجتماعی، ایندکس‌ها و سخت‌سازی ACL. وضعیت دقیق را با `supabase migration list` بررسی کنید.

## متغیرهای محیطی

در تنظیمات محیطی GitHub Actions و Vercel این دو مقدار لازم‌اند:

- VITE_SUPABASE_URL
- VITE_SUPABASE_PUBLISHABLE_KEY

فقط کلید publishable در کلاینت استفاده می‌شود. کلید service_role یا کلید secret هرگز نباید در وب‌سایت یا APK قرار بگیرد.

## ساخت وب و اندروید

پس از استخراج naqsh-negar-source.zip:

~~~bash
bash scripts/restore-overlay.sh
node source-overlay/apply-overlay.mjs ./naqsh-negar
cd naqsh-negar
npm ci
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
~~~

برای ساخت وب در Vercel، vercel.json همین مراحل را خودکار اجرا می‌کند. GitHub Actions نیز overlay را قبل از تست و ساخت اعمال می‌کند.

## نقشهٔ ادامهٔ توسعه

1. تکمیل پروفایل عمومی، اعلان‌های اجتماعی و تعامل زنده
2. تکمیل پیام‌رسانی اجتماعی و کنترل حریم خصوصی، مسدودسازی و گزارش کاربران
3. بازارچهٔ چندفروشنده، گردش سفارش، ارسال و تسویهٔ فروشنده
4. اتصال درگاه پرداخت واقعی، webhook و تطبیق امن پرداخت
5. تکمیل داشبورد مدیریت، گزارش‌گیری، پشتیبان‌گیری و پایش عملیاتی
6. آزمون end-to-end وب و اندروید و تست روی دستگاه واقعی

هیچ قابلیتِ صرفاً نمایشی به‌عنوان قابلیت متصل به سرور یا آمادهٔ بهره‌برداری معرفی نمی‌شود.
