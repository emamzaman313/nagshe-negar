# نقش‌نگار — بررسی فنی و وضعیت اجرا
تاریخ: ۲۰۲۶-۱۱-۲۶

## معماری
- وب: React 19، TypeScript، Vite، React Router و Supabase JS.
- اندروید: Capacitor 8؛ بستهٔ وب مشترک در Android WebView.
- PWA: سرویس‌کار برای پوسته و فایل‌های ایستا.
- پروژهٔ زنده Supabase: jnccbdgtdrbufzemmnod (فعال).
- مخزن: emamzaman313/nagshe-negar، شاخه main.

## قابلیت‌های موجود در منبع پایه
- ثبت‌نام/ورود ایمیلی و مسیر OTP.
- طراح بلوک چهل‌تکه و دفتر خصوصی پروژه‌ها.
- فروشگاه تک‌فروشنده، سبد خرید، سفارش و رسید پرداخت دستی با بازبینی مدیر.
- آموزش‌ها، دوره‌ها و پیشرفت درس.
- گالری آثار با رضایت انتشار، صف بازبینی و گزارش.
- اتاق‌های موضوعی، پیام خصوصی، پشتیبانی و اعلان‌های درون‌برنامه‌ای.
- پنل مدیریت محتوا برای کالا، آموزش، دوره، دسته و صفحه؛ تنظیمات فروشگاه، ثبت رویداد مدیریتی، بررسی پرداخت و صندوق پشتیبانی.

## لایه اجتماعی افزوده‌شده
- فید آثار با انتشار عکس/ویدئو، دنبال‌کردن، پسندیدن، دیدگاه، ذخیره و اشتراک‌گذاری.
- ریلز عمودی با پخش بی‌صدا و توقف خودکار خارج از محدوده دید.
- حذف فراداده‌های EXIF پشتیبانی‌شده با بازرمزگذاری تصویر در مرورگر.
- صف مدیریت برای تأیید، رد و پنهان‌سازی پست‌ها.
- هفت جدول اجتماعی با RLS و bucket خصوصی qnr-social-media.
- سه migration اجتماعی در Supabase اعمال شده‌اند:
  - 20261126095835_qnr_social_network
  - 20261126095938_qnr_social_metrics_security_and_indexes
  - 20261126100341_qnr_social_acl_hardening
- مجوزهای TRUNCATE/REFERENCES/TRIGGER برای anon و authenticated از جدول‌های اجتماعی برداشته شده‌اند؛ RLS به‌تنهایی TRUNCATE را کنترل نمی‌کند.
- نمای شمارنده‌ها security_invoker است و از تابع تجمیع محدود در schema خصوصی استفاده می‌کند.

## استقرار و آزمون‌های تأییدشده
- دامنه اصلی Vercel: https://naghsh-negar.vercel.app
- آخرین بررسی صفحه اصلی و مسیرهای /social و /reels: پاسخ HTTP 200.
- استقرار Vercel روی commit 7fc1688 READY شد؛ تغییرات بعدی مجوزهای دیتابیس و مستندات هنوز باید در Vercel منتشر شوند.
- GitHub Pages و workflow وب روی commit 65426cdfbc188c063486161e830d0de581d43af9 موفق شدند.
- workflow ساخت APK اندروید روی همان commit موفق شد؛ این APK دیباگ است، نه نسخهٔ Release امضاشده.
- Vercel build موفق بوده و TypeScript و Vite build را گذرانده است.

## موارد باز و محدودیت‌ها
- پنل مدیریت موجود هنوز پنل کامل مدیریت کاربران/نقش‌ها/مسدودسازی/تنظیمات برند/اعلان‌های سراسری نیست؛ بخش اجتماعی فقط صف بازبینی دارد.
- مسیر فروشندگی هنوز کامل نیست؛ بازار چندفروشنده و مدیریت فروشندگان پیاده‌سازی نشده‌اند.
- پرداخت خودکار و webhook درگاه وجود ندارد؛ پرداخت فعلی دستی است.
- ترنسکد ویدئو، thumbnail و adaptive streaming ریلز باقی است.
- آزمون end-to-end با حساب واقعی برای ثبت‌نام، بارگذاری، signed URL، پسند، دیدگاه و moderation انجام نشده است.
- یک نقش admin در دیتابیس وجود دارد؛ هویت حساب آن در گزارش عمومی نمایش داده نمی‌شود.
- Supabase Security Advisor دیگر خطای Security Definer View ندارد؛ تنها هشدار امنیتی فعلی Leaked Password Protection غیرفعال است و باید از Auth settings فعال شود.
- npm audit در build اخیر ۶ آسیب‌پذیری وابستگی (۱ کم‌خطر و ۵ متوسط) گزارش کرده است؛ باید با ارتقای کنترل‌شدهٔ وابستگی‌ها رفع شوند.
- Vite هشدار bundle بزرگ‌تر از ۵۰۰ کیلوبایت داده است؛ code splitting مرحلهٔ بهینه‌سازی بعدی است.
- تست روی دستگاه Android واقعی، دسترس‌پذیری و انتشار Release امضاشده باقی مانده است.
