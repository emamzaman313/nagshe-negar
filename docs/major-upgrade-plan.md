# ارتقای بزرگ نقش‌نگار — برنامه اجرایی

این سند نقشهٔ پیاده‌سازی روی کدبیس فعلی React/Vite + Capacitor و پروژهٔ Supabase موجود است. طراح بلوک چهل‌تکه، هویت بصری، گالری، دوره‌ها، سفارش‌ها و گفت‌وگوهای فعلی باید حفظ شوند.

## فاز ۱ — زبان بصری سراسری (در شاخه premium-visual-system)

- توکن‌های طراحی یکپارچه برای رنگ، سایه، گوشه‌ها، فاصله و فوکوس.
- رنگ‌های اصلی: سبز جنگلی و یشمی برای اعتماد و آرامش؛ کرم کاغذی برای حس پارچه و کاردستی؛ طلایی محدود برای کیفیت ممتاز؛ مرجانی برای هشدار و اقدام‌های ظریف.
- پس‌زمینهٔ چندلایه با بافت بسیار ملایم و نور واکنش‌گرا به حرکت نشانگر ماوس.
- ارتقای کارت‌ها، فرم‌ها، دکمه‌ها، جدول‌ها، گالری و تعامل hover/focus.
- واکنش‌گرایی موبایل و پشتیبانی از prefers-reduced-motion و صفحه‌کلید.
- این لایه در کدبیس مشترک اعمال می‌شود تا وب و Android یک هویت داشته باشند.

## فاز ۲ — جامعهٔ اجتماعی

- تکمیل پروفایل عمومی، جست‌وجوی هنرمند، دنبال‌کردن و تنظیمات حریم خصوصی.
- فید رتبه‌بندی‌شده، اعلان‌های لایک/دیدگاه/دنبال‌کردن و به‌روزرسانی زنده.
- ریلز با کنترل پخش، گزارش محتوا، بارگذاری امن و مدیریت رسانه.
- مسدودسازی و محدودسازی تعاملات؛ ابزارهای ضداسپم و محدودیت نرخ.
- تست End-to-End با حساب‌های واقعی، نه دادهٔ نمونه.

## فاز ۳ — پیام‌رسانی

- تکمیل پیام خصوصی با وضعیت ارسال/خوانده‌شدن، نشانگر آنلاین، پیوست فایل و تصویر.
- کانال‌های Realtime با مجوز عضویت، کنترل مزاحمت و گزارش پیام.
- صفحهٔ صندوق ورودی و اعلان‌های قابل تنظیم.

## فاز ۴ — بازارچهٔ چندفروشنده

- درخواست فروشندگی و تأیید مدیر.
- فروشگاه اختصاصی هر فروشنده، ثبت محصول و صف تأیید محتوا.
- سفارش‌های چندفروشنده، snapshot قیمت و فروشنده، موجودی و رویدادهای سفارش.
- گردش کار مرجوعی/لغو، کارمزد و تسویهٔ فروشنده؛ اطلاعات ارسال مشتری فقط برای افراد مجاز.
- درگاه پرداخت فقط پس از انتخاب ارائه‌دهنده، تنظیم اسرار سمت سرور و پیاده‌سازی webhook امضاشده فعال می‌شود. رسید دستی فعلی حفظ خواهد شد.

## فاز ۵ — پنل مدیریت و عملیات

- نقش‌ها و مجوزهای حداقلی (RBAC)، تعلیق و رفع تعلیق کاربر، هشدار و ثبت دلیل.
- صف بررسی پست‌ها، گزارش‌ها، محصولات، فروشندگان و رسیدها.
- گزارش فروش و تعامل، اعلان‌های سراسری، تنظیمات برند و پرچم قابلیت‌ها.
- ثبت رویداد ممیزی برای تمام عملیات حساس.
- پشتیبان‌گیری و بازیابی با نسخه‌بندی؛ بازیابی فقط با کنترل و تأیید مدیر ارشد.

## فاز ۶ — انتشار و تضمین کیفیت

- تست واحد، تست RLS، تست API و تست End-to-End برای نقش‌های کاربر/فروشنده/مدیر.
- ساخت Preview در Vercel؛ انتشار Production فقط بعد از عبور تست‌ها.
- ساخت APK اندروید، تست روی دستگاه واقعی و سپس امضای Release با کلید مالک.
- پایش خطاها، کارایی، حجم bundle و دسترس‌پذیری.

## وضعیت زیرساخت در شروع این ارتقا

- Supabase پروژهٔ نقش‌نگار فعال است؛ ۳۴ جدول عمومی و مهاجرت‌های پایه و اجتماعی در ledger ثبت شده‌اند.
- جداول اجتماعی دارای RLS هستند؛ bucket رسانهٔ اجتماعی خصوصی است.
- Vercel متغیرهای VITE_SUPABASE_URL و VITE_SUPABASE_PUBLISHABLE_KEY را در Production/Preview/Development دارد.
- هشدار امنیتی باقیمانده: Leaked Password Protection در Supabase Auth غیرفعال است.
- پرداخت آنلاین و تسویهٔ واقعی فروشنده هنوز آماده نیست؛ تا انتخاب درگاه و webhook امن نباید به‌عنوان قابلیت فعال معرفی شوند.
- APK Release امضاشده و تست دستگاه واقعی هنوز تأیید نشده است.

## معیار کیفیت کد

تعداد خط معیار کیفیت نیست. از تولید ۷۰۰۰ خط تکراری یا CSS فشردهٔ بی‌ساختار خودداری می‌کنیم؛ هر بخش باید مؤلفهٔ قابل استفادهٔ مجدد، رفتار واقعی، دسترس‌پذیری و تست داشته باشد. رشد حجم UI باید نتیجهٔ قابلیت‌ها و اجزای واقعی باشد.
